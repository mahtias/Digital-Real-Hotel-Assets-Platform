🏨 Hotel Tokenization & Investment
✅
Hotel Asset Tokenization (HAT ERC-20)
HotelTokenFactory + HotelAssetToken deployed on Base Sepolia. Admin deploys hotel tokens; marketplace shows on-chain totalSupply + soldPercentage.
Done
✅
Fractional Investment — starting from $1
Buy HAT tokens in any amount. 2% platform fee calculated and stored per investment. Portfolio page shows HAT balance, yield, earned.
Done
✅
Platform Transaction Fee (2%) + Treasury Recording
2% fee on every HAT investment. After confirmation, 2 Treasury records created automatically: PLATFORM_REVENUE (50%) + DRA_BUYBACK (50%).
Done
✅
Risk Reserve Fund — 5% of Every Hotel Payout
Settlement service deducts RESERVE_FUND_PERCENT (default 5%) before sending USDC to hotel wallet. Reserve recorded in Treasury as type="RESERVE".
Done
💰 DRA Token & Yield
✅
DRA Token Minting on Investment
draService.mintReward() called after every investment — mints DRA to investor wallet at DRA_EARN_RATE/USDC. Non-blocking fire-and-forget.
Done
✅
ESG Reward Claim → On-Chain DRA Transfer
When user claims ESG reward, backend mints actual DRA tokens to their wallet via draService.mintReward(). Idempotency guard prevents double-claim.
Done
✅
DRA Staking — Governance + APY
Lock periods (30/90/180/365 days), APY rates (8/12/18/25%), voting power multiplier. APY validated server-side against lock period tier.
Done
✅
Yield Distribution (HotelYieldVault)
settlementService processes hotel payouts on-chain (real USDC transfer). Snapshots investor balances, distributes to investor_yields table.
Done
✅
Dual Token System — DRA + HAT
DRA: governance, staking, minted on investment & ESG claims. HAT: represents hotel asset ownership, tied to yield streams.
Done
